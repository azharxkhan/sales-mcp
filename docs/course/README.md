Read them in order, or start with 3 and 4: the domain was built before any MCP code, and those two need no knowledge of MCP.

Every chapter has the same shape: what you'll build, why it matters, concepts, step by step, what can go wrong, check yourself, and the code. Terms in bold are defined in the [domain glossary](../domain/glossary.md).
